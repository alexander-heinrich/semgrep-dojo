About

Semgrep Dojo is an unofficial practice site for learning the Semgrep pattern syntax and rule syntax, modelled on the interactive tutorial at semgrep.dev/learn. It is not affiliated with Semgrep, Inc.

Every challenge asks for a rule that matches exactly the marked lines of a snippet taken from a real open-source C# project. Grading is the same as semgrep --test: the set of matched start lines must equal the set of // ruleid: lines. Some challenges additionally compare exact ranges (for focus-metavariable) or the rendered fix.

How rules run in the browser

Your rule runs locally on a WebAssembly build of the Semgrep OSS engine (js_of_ocaml + emscripten), built from the source tree at tag v1.81.0 (July 2024) — the last release that still contains the browser build tooling, which Semgrep later moved into its proprietary repository. The C# and Python parsers come from the same build (Python is only needed for metavariable-comparison). Nothing is sent to a server.

The build, its recipe and its verification suites are in Semgrep-WASM. For C#, the only language this site runs, the build behaves exactly like Semgrep 1.172.0 on every probe we ran: the rule-syntax operators, taint mode, autofix and message rendering, and C# 9 to 14 syntax samples. All challenges are validated against a current Semgrep CLI when the site is built, and a parity script confirms the browser engine agrees for every one of them. The rule-syntax half of that evidence is largely language-independent; the parser half is verified for C# alone. Two years of newer releases are still missing, so if you find a rule that behaves differently, the CLI result is the reference.

Practicing from the terminal

git clone https://github.com/alexander-heinrich/semgrep-dojo && cd semgrep-dojo
python3 scripts/check.py challenges/csharp/1-basics/04-metavariables --start
$EDITOR workspace/04-metavariables/rule.yaml
python3 scripts/check.py challenges/csharp/1-basics/04-metavariables workspace/04-metavariables/rule.yaml
