About

Semgrep Dojo is an unofficial practice site for learning the Semgrep pattern syntax and rule syntax, modelled on the interactive tutorial at semgrep.dev/learn. It is not affiliated with Semgrep, Inc.

Every challenge asks for a rule that matches exactly the marked lines of a snippet taken from a real open-source C# project. Grading is the same as semgrep --test: the set of matched start lines must equal the set of // ruleid: lines. Some challenges additionally compare exact ranges (for focus-metavariable) or the rendered fix.

How rules run in the browser

Your rule runs locally on a WebAssembly build of the Semgrep OSS engine that Semgrep published to npm in April 2023 (@semgrep/engine@1.17.1-alpha.2 with the C# and Python parsers). Nothing is sent to a server. The snapshot is old, so a few features behave differently from current Semgrep:

  • pattern-regex, pattern-not-regex, metavariable-regex, metavariable-analysis and paths do not work — those challenges are marked CLI only and are practiced with scripts/check.py and your installed Semgrep.
  • Severities CRITICAL/HIGH/MEDIUM/LOW are mapped to ERROR/WARNING/INFO before running.
  • Rendered autofixes are computed by the page from your fix: and the metavariable bindings.
  • The C# parser predates C# 11, so targets avoid raw string literals, list patterns, primary constructors and collection expressions.

All challenges are additionally validated against a current Semgrep CLI when the site is built, and a parity script confirms the browser engine agrees for every challenge that is not CLI-only.

Practicing from the terminal

git clone https://github.com/alexander-heinrich/learn-semgrep && cd learn-semgrep
python3 scripts/check.py challenges/csharp/1-basics/04-metavariables --start
$EDITOR workspace/04-metavariables/rule.yaml
python3 scripts/check.py challenges/csharp/1-basics/04-metavariables workspace/04-metavariables/rule.yaml
