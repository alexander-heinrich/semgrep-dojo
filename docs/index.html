Learn Semgrep syntax on real C# code

Each challenge gives you a snippet from an open-source .NET project and asks for a rule that matches exactly the marked lines. Your rule runs in the browser on a WebAssembly build of the Semgrep engine — nothing leaves your machine. Cheatsheet entries and rule keys are covered one at a time, from $METAVARIABLES to taint mode.
